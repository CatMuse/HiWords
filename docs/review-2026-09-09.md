## 项目结构与检查重点

项目使用 TypeScript、Obsidian API 和 esbuild。`main.ts` 负责插件初始化，`VocabularyManager` 汇总 Canvas 与 `.hiwords` 词库，卡片注册表负责类型能力和显示模块，编辑器与 mutation service 分别处理编辑和持久化。

未推送功能主要包含 SecretStorage、上下文例句查找、弹窗操作、结构化编辑器、AI 草稿和多类型知识卡。本轮重点检查这些功能之间的数据读写、生成内容合并、字段类型与设置存储；并非全部界面和平台的穷尽验证。
