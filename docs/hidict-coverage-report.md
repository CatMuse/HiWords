# Kaikki 覆盖率与 HiDict 扩充建议

2026-10-04 对当前一万词 `.hidict` 进行完整快照扫描；本轮未修改词典、插件或设置。

## 当前一万词覆盖率

| 指标 | 数量 | 比例 |
|---|---:|---:|
| Kaikki 有对应词条 | 9,999 | 99.99% |
| 至少有一个 IPA 音标 | 9,632 | 96.32% |
| 明确 UK／RP 标注的音标 | 6,046 | 60.46% |
| 明确 US／General American 标注的音标 | 6,050 | 60.50% |
| 同时有明确英美标注 | 5,647 | 56.47% |

只按大小写归一化后的拼写精确匹配，汇总同一词的各词性／义项。UK/US 包含相应地区变体，不保证是唯一标准读音；无口音标签的 IPA 不归为英音或美音，不按音频文件名猜测。2,179 词有多个 UK 读音，2,339 词有多个 US 读音，不能随意只保留第一项。唯一未匹配词为 `saut`。这是词条覆盖率，不是阅读文本覆盖率。

## 用户举例

三个词在现有一万词中均缺失，但完整 ECDICT 都有中文释义。

| 词 | ECDICT frq 排名 | Kaikki 词条 | 本快照明确英美音标 |
|---|---:|---|---|
| customizable | 31,464 | 有 | 未提取到 IPA |
| malleable（含大写查询） | 18,412 | 有 | 有 |
| extensible | 37,875 | 有 | 未提取到 IPA |

首版仅按 frq 筛选一万词，最后入选的来源排名是 12,280，所以这些词被选词规则排除。提高词条数量会改善查词范围，但不能解决所有词的双音标缺失。

## 从 ECDICT 直接转换的范围选择

共同规则：有中文释义的单个 ASCII 英文词（允许连字符、撇号），大小写去重，排除明确指向另一原词的屈折词条。保留这些原词的 forms 索引；不包含短语。本次使用原有固定 ECDICT CSV，SHA-256 见 JSON 报告。

| 候选范围 | 原词条数 | 紧凑 JSON 词条体积估算 |
|---|---:|---:|
| 全部有 frq 排名的词 | 37,067 | 14.47 MiB |
| 有 frq 或 BNC 排名 | 50,976 | 19.02 MiB |
| 有 frq／BNC／考纲／柯林斯星级任一标记 | 51,796 | 19.32 MiB |
| 以上共同规则下的全部原词 | 344,449 | 110.17 MiB |

体积通过逐条转换和 UTF-8 序列化求和；不含新增音标和文件元信息，并非已生成的发布文件大小。美化 JSON 会明显更大。推荐先采用 51,796 词版本；三个举例词均已包含。候选中 14,729 词没有 frq，五级词频应显示未知，不能用 BNC 排名冒充 frq 排名。这个候选集中可提取双音标的词有 15,433（约29.80%），范围扩大后双音标覆盖比例下降。

如果希望查专业词，可另做更广范围版本，后续也可单独增加短语、缩写和拼写变体。几十万词的 JSON 不宜直接默认加载，需要评估实际内存、索引和移动端体验。

## 推荐改造路线

现有 `.hidict` 本来就由 ECDICT 转换而来，可以继续利用完整源数据，无需自行逐词编写。推荐 ECDICT 提供中文释义、词形、词频，Kaikki 补充确认口音的音标。Kaikki 的英语数据主要提供英文释义，整体替换会改变当前中文查词体验；中文译词并不等于完整的中文释义。

补音标前扩展字段级来源和多读音表示，更新格式版本及读取器。保留 ECDICT 原音标作为未分类后备，不将同一音标复制为英美两份。按词性／义项筛选读音，而非任取候选。Wiktionary 数据需保留署名和相应许可证要求，不能将整个混合词典都标为 MIT。
