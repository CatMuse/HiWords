# Canvas 布局与卡片尺寸

卡片宽度/高度的单位是 Canvas 坐标中的 px，默认 260 × 120。设置界面要求正整数。保存设置不会遍历词库或立即重排已有文件。

- 通过 HiWords 新建 Canvas 词卡时，不论自动布局是否启用，都使用设置宽高。
- 开启自动布局后，CanvasEditor 的添加、编辑、删除词条操作在 `vault.process` 原子写回中调用 `normalizeLayout`。参与布局的非分组节点统一尺寸，从 (50, 50) 开始按三列排列，水平和垂直间距均为 20。
- 关闭自动布局后，已有节点的位置和尺寸不变；新节点仍使用设置尺寸并选择初始位置。
- Mastered / 已掌握分组内的节点不参与上述重排。状态判断是几何包含关系；普通分组并没有同样的保护。
- 设置不影响 .hiwords 编辑器卡片、悬浮词卡或 Markdown 内容。备注和例句收藏走独立的无重排写回。掌握状态保存在插件设置中，不会触发 Canvas 分组布局。
- `layoutGroupInner` 提供两列分组布局，但当前没有调用方；不能把它描述为现有自动触发行为。

本次补充宽高说明，并修正自动布局说明，明确它会覆盖参与节点的手动位置。修复了中文“已掌握”分组未被布局保护，以及只改节点颜色也触发重排的问题。

仍有优化空间：当前会处理除受保护分组成员以外的所有非分组节点（包括链接节点），不只处理词卡；固定三列也不检测与其他分组重叠。后续可以考虑仅重排选定词卡、保护所有手动分组，以及提供显式“立即整理”操作。本次没有改变这些布局策略，避免意外移动用户现有 Canvas。

验证：17 项测试通过，含自动布局关闭时不改变节点、中文掌握分组保护、三列尺寸/间距及改色不重排。生产构建和相关官方 ESLint 检查通过。未修改任何用户 Canvas 文件。
